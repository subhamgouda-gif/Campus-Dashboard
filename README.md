# Campusly Student Dashboard

A responsive student dashboard demo built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Demo features

- Student overview with attendance, marks, classes, and assignments
- Weekday timetable filters
- Subject score cards
- Dismissible notifications
- Campus announcements with a mark-as-read control
- Responsive navigation for mobile screens

All student information and academic results are sample data. This project has no login, backend, or connection to a real school system.
